# Pollitos del Daily 🐣

App 100% frontend para sortear el orden de los updates en una reunión.

1. Escribe los nombres de los participantes (uno por línea o separados por comas).
   Debajo eliges si cada persona es de 💻 programación o de 🎨 diseño: los
   mensajes de despedida y de la pantalla final cambian según su rol.
2. Cada participante es un pollito con un número; los nombres se asignan al azar.
3. Haz click en un pollito: levanta el ala y su etiqueta muestra el nombre.
4. Pulsa **Siguiente** (o `→`) y el pollito se va. Luego elige al siguiente.

Cada pollito sale de una forma distinta (al azar, sin repetirse hasta usar
todas): en carro 🚗, en avión ✈️, aplastado por un yunque 💥, mirando el
reloj y subiendo al bus 🚌, con un jetpack 🚀, con globos 🎈, volando 🐥 o atrapado
por unos vaqueros a caballo 🤠.
Para probar una salida concreta (solo aplica al siguiente pollito; luego
vuelve a ser al azar): `index.html?salida=carro` (también `avion`,
`yunque`, `bus`, `cohete`, `globos`, `volando`, `vaqueros`).

Hay 7 variantes de pollito: guante, casco, cabello, zapatos, tatuaje, gafas y moño.

## Uso

Abre `index.html` en el navegador. No necesita build ni servidor
(también se puede publicar tal cual en GitHub Pages).
